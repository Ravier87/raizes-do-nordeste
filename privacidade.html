Política de Privacidade

A sua privacidade é importante para nós. Esta página explica como os dados pessoais são tratados durante a utilização do protótipo Raízes do Nordeste.

Aviso: este site faz parte de um projeto acadêmico e possui funcionalidades demonstrativas. Ele não representa um serviço comercial em operação.

1. Quais dados são utilizados?

Durante a utilização do protótipo, podem ser utilizados:

  • Nome completo;
  • Endereço de e-mail;
  • Número de telefone;
  • Dados demonstrativos de pedidos, como produtos, valores e forma de recebimento;
  • Preferências necessárias para simular a navegação e as funcionalidades do sistema.

2. Para que os dados são utilizados?

Os dados são utilizados para demonstrar funcionalidades como cadastro de clientes, identificação no perfil, organização de pedidos e navegação pelo sistema.

No protótipo, essas operações têm finalidade exclusivamente demonstrativa e acadêmica. Não são realizadas vendas reais nem cobranças financeiras.

3. Como os dados são armazenados?

Algumas informações são armazenadas no próprio navegador por meio do recurso localStorage. Isso permite que os dados demonstrativos permaneçam disponíveis entre diferentes páginas do protótipo.

Esse armazenamento não corresponde a um banco de dados centralizado. As informações podem ser removidas quando os dados do site são apagados no navegador.

Como se trata de uma demonstração, não utilize senhas reais, dados bancários verdadeiros ou outras informações sensíveis.

4. Compartilhamento de informações

O protótipo não foi desenvolvido para realizar o compartilhamento comercial de dados pessoais com terceiros. As funcionalidades de pagamento são simuladas e não processam transações financeiras reais.

O funcionamento atual utiliza recursos do navegador e não implementa um serviço de autenticação ou processamento de pagamentos em produção.

5. Segurança das informações

O protótipo possui limitações próprias de uma aplicação front-end. O armazenamento local não deve ser considerado adequado para guardar senhas reais ou informações financeiras.

Em um sistema real, seriam necessárias medidas adicionais de segurança, controle de acesso, proteção de dados e gerenciamento de autenticação.

6. Direitos do titular dos dados

A Lei Geral de Proteção de Dados Pessoais (LGPD) estabelece direitos relacionados ao tratamento de dados pessoais, observadas as condições e os procedimentos aplicáveis.

Entre esses direitos, estão:

  • Solicitar confirmação sobre o tratamento de dados;
  • Solicitar acesso aos dados pessoais;
  • Solicitar correção de informações incompletas, inexatas ou desatualizadas;
  • Solicitar a eliminação de dados pessoais, quando aplicável;
  • Obter informações sobre o tratamento realizado.

No protótipo, os dados demonstrativos armazenados localmente podem ser apagados pelo próprio usuário ao limpar os dados do site no navegador.

7. Consentimento e transparência

No cadastro demonstrativo, o usuário encontra uma opção para indicar que leu e concorda com esta política. A finalidade é representar o fluxo de consentimento no protótipo.

Essa interação não registra, por si só, um consentimento em um sistema centralizado nem substitui os demais deveres legais relacionados ao tratamento de dados.

8. Contato e dúvidas

Para fins deste projeto acadêmico, não há um canal real de atendimento de privacidade implementado.

Contato demonstrativo: contato@raizesdonordeste.example

O endereço acima é fictício e serve apenas para ilustrar como um canal de contato poderia ser apresentado em uma versão futura do sistema.
